# Vice Cover Studio

A GTA 6-style cover art maker: your photo and caption become a multi-panel poster cover — hero panel plus side panels, each with its own photo, crop and zoom — in a Vice City sunset or neon grade, exported as a PNG in 1080×1080, 1080×1350 or 1920×1080. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Pick a layout, a grade and an export size, drop in photos (or use the two samples), click a photo into a panel, drag it to crop, type your title and subtitle, and hit Export PNG. Everything runs offline in the browser — photos never leave the machine. All art, lettering and fonts are the maker's own; no Rockstar Games logo, artwork or font is used.
